# Notes

For developing the workflow itself over time: guides, research, ideas and decisions. Not instructions agents follow (those are the skills and templates).

```
workflow-guide.md   the map of the workflow as it stands (from the first project)
ideas.md            backlog of things to try
research/           notes on other people's workflows, tools, articles
decisions/          why the workflow is the way it is (short ADR-style notes)
trials.md           changes on trial (beta track) and their verdicts
v1.md               the toolbox as tagged v1.0 and in use
```

How a change flows: an idea in `ideas.md` -> research in `research/` if needed -> try it on one project -> if it sticks, change the skill/template, add a line to `CHANGELOG.md`, and a note in `decisions/` if it was a real trade-off. The full loop, and where each kind of note goes, is in [../DEVELOPING.md](../DEVELOPING.md).
