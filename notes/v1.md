# Toolbox v1

The version of the toolbox in daily use: imported from the first project's workflow (`examples/poreader/`), then made generic. Tagged `v1.0` on GitHub. v1 changes only for fixes; new ideas go to the v2 roadmap (`.scratch/map-toolbox-roadmap/map.md`, later `notes/roadmap.md`).

To set a project up from exactly v1: check out the tag (`git checkout v1.0` in a copy of this repo) and run `/setup-workflow` from there, or pass a project's `workflow_version` to `/refit-workflow`.

## What v1 is

- **Presets** (`presets/`): `full` (phases, STATUS, HANDOFF, PLAN, specs and work tickets in `.scratch/`), `fast-lane` (small changes inside a `full` project), `lite` (LOG only), `team` (placeholder).
- **Platforms** (`platforms/`): `github` and `azure`.
- **My skills** (`skills/`):
  - core: `start-session`, `end-session`, `ship`
  - optional: `pr-explainer`, `thermo-nuclear-code-quality-review`, `day-log`, `vault-note`
  - global: `setup-workflow`, `refit-workflow`
- **Matt Pocock's skills plugin** for thinking, planning, building and reviewing: `grill-with-docs`, `to-spec`, `to-tickets`, `implement`, `tdd`, `code-review`, `pr`, `wayfinder` and others.
- **Templates** (`templates/`): `CLAUDE.md`, `docs/agents/*`, and the `full` state files.
- **Tools** (`tools/`): `Install-Workflow.ps1`, `Install-GlobalSkills.ps1`, `New-AzurePr.ps1`, `Export-StandaloneHtml.ps1`.

## The v1 pipeline

```
/start-session
  /grill-with-docs -> /to-spec -> /to-tickets -> /implement -> /code-review -> /ship
/end-session
/day-log (optional)
```

The full picture, with diagrams: `notes/workflow-guide.md`. Day-to-day use: `USING.md`.
