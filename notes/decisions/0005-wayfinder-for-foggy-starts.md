# Foggy project starts (and foggy phases) begin with a wayfinder map

Status: **exploring** (2026-11-22). Try it on the next new project; keep or drop afterwards.

Matt Pocock's `wayfinder` plans an effort too big for one session and too foggy to list its decisions yet: it charts a map (destination, decisions so far, fog, out of scope) and decision tickets (research, prototype, grilling, task), then resolves one ticket per session until nothing is left to decide. In preset `full`, a new project whose way to a plan is not clear starts with a map whose default destination is `docs/PLAN.md` with phases, Phase 1 sliced into a Specs list, and the first ADRs and glossary terms, so the map hands straight over to the normal pipeline. A clear start skips it and goes to `grill-with-docs`. `/setup-workflow` offers the exact line to type (wayfinder is user-started only); `/start-session` shows an active map's frontier; `research/` branches it pushes are archived by the `/end-session` sweep. Not used in `fast-lane` or `lite`. Trade-off: several sessions and parallel research subagents (token-heavy) up front, in exchange for not speccing on guesses. The destination is meant to be customised per project.
